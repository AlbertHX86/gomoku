# 五子棋

[English](README.md) | 中文

一个在浏览器里运行的极简五子棋。没有广告，不用注册，也没有任何依赖。它和 [舒尔特方格](https://github.com/AlbertHX86/schulte-grid)、[数独](https://github.com/AlbertHX86/sudoku) 是同一套外观的小游戏。

**在线试玩：** https://alberthx86.github.io/gomoku/

## 怎么玩

1. 选择模式：和电脑对战的 **简单**、**中等**、**困难**，或者同一台设备上的 **双人** 对战。
2. 黑方先行。和电脑对战时你执黑。
3. 在 15×15 的棋盘上点击交叉点落子，双方轮流。
4. 先在横、竖或斜方向连成 **五子或以上** 的一方获胜。棋盘下满则为平局。
5. 第一手落子时开始计时。最后一手棋上有一个蓝点，获胜的五子会被标出。
6. 点击“悔棋”可以撤回，每局最多 3 次。和电脑对战时会撤回你的上一手和电脑的应手；双人模式撤回最后一手，双方共用 3 次。
7. 点击“重置”开始新的一局。

小技巧：尽早堵住对手的“活三”（两端都空着的三连），并尽量同时制造两个威胁。

右上角可以切换亮色和暗色，以及中文和英文。默认跟随系统主题和浏览器语言。

## 记录

每个模式单独记录：累计比分（你对电脑，或黑对白），以及最近 10 局的结果、手数、用时和悔棋次数。记录保存在浏览器的 `localStorage` 里，不会上传到任何地方。

- 同一设备的同一浏览器会一直保留记录，在线离线都可以。
- 不同浏览器、不同设备之间不同步。
- 清除浏览器数据会删掉记录。也可以点“清空”，删除当前模式的记录。

## 本地运行

游戏只有三个静态文件：`index.html`、`style.css`、`app.js`，不需要构建。

```bash
git clone https://github.com/AlbertHX86/gomoku.git
cd gomoku
```

然后直接用浏览器打开 `index.html`，或者起一个本地服务：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

直接打开文件和通过 `localhost` 访问，在浏览器看来是两个不同的网站，记录分开保存。

## 五子棋与大脑

下五子棋需要同时记住多个威胁、预判对手、提前规划，这些都是前额叶皮层的核心功能。一项五子棋任务的 fMRI 研究发现，较难的落子会激活前额叶和顶叶；在老年人中，经常玩棋类游戏与认知下降更少有关。不过这些研究要么样本小，要么是观察性研究，都不能说明下五子棋会改变大脑。网页中的“文献”部分有带引用的简要综述。
